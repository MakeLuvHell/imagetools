# Image Tools v0.2.3

会话整理与本地工作区体验更新。

## 改进

- 会话可置顶或取消置顶，重要创作任务保持在侧栏顶部。
- 支持创建、重命名和删除本地项目，并在项目下组织会话。
- 会话可在项目与普通会话之间移动；删除项目不会删除会话或生成记录。
- 既有本地数据库自动升级，保留 Provider、会话、生成轮次和图片历史。

## Windows 安装包

GitHub Actions 将生成并附加：

- Windows x64 NSIS `.exe`
- Windows x64 MSI `.msi`

安装器继续使用 Image Tools 图标和简体中文界面。当前安装包没有代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。

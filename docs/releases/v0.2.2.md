# Image Tools v0.2.2

Windows 桌面交互体验更新。

## 改进

- 为菜单、弹窗、搜索、Toast 和任务内容加入克制快速的交互动效。
- 图片参数菜单现在锚定触发按钮，窗口缩放后会自动重新定位。
- 参考图菜单复用相同的视口边界与自动翻转逻辑。
- Provider 设置中的“取消”现在会关闭弹窗并恢复触发按钮焦点。
- 支持 Windows“减少动态效果”系统偏好。
- 修复快速重复开关菜单时，旧退场动画可能隐藏新状态的问题。

## Windows 安装包

GitHub Actions 将生成并附加：

- Windows x64 NSIS `.exe`
- Windows x64 MSI `.msi`

安装器继续使用新 Image Tools 图标和简体中文界面。当前安装包没有代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。

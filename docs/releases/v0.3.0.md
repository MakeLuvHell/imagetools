# Image Tools v0.3.0

v0.3.0 把桌面后端完整迁移到 Image Tools 自身的 Rust/Tauri 进程。关闭主窗口后，不再有独立的 backend 程序需要继续运行或单独清理。

## 主要变化

- 正式版只有一个应用进程：`Image Tools.exe` 同时承载桌面窗口和本地数据/生成逻辑。
- 新增 Windows x64 Portable ZIP，压缩包内只有 `Image Tools.exe`，解压后即可运行。
- 保留 Windows x64 MSI，支持正常安装和卸载。
- 前端资源随应用打包，通过 Tauri IPC 调用 Rust；应用不启动本地 UI/API 服务。
- Provider、项目、会话、固定会话、生成历史、参考图、结果图、数据目录和系统/浅色/深色主题功能保持可用。
- 结果图使用只接受图片 ID 的应用内媒体协议，并通过 Windows 原生保存对话框导出。
- 数据库继续使用 schema v2；v0.3.0 没有新增数据库迁移，面向现有 v0.2.3 工作区保持格式兼容。

## Windows 资产

```text
Image-Tools-v0.3.0-Windows-x64.msi
Image-Tools-v0.3.0-Windows-x64-Portable.zip
```

系统要求：Windows x64 和可用的 Microsoft Edge WebView2 Runtime。

## 数据与升级

安装版默认继续使用 `com.imagetools.desktop` 对应的应用数据目录。自定义工作区、`workbench.sqlite3`、`images/`、`uploads/` 和兼容 `settings.json` 的布局不变。

升级前建议备份整个工作区数据目录。正式发布 workflow 会用脱敏 schema-v2 工作区执行 v0.2.3 → v0.3.0 → v0.2.3 安装、打开和回滚门禁；默认验证 run 不公开 Release，只有显式 `publish_release=true` 才发布资产。门禁尚未完成前，不应把格式兼容设计当作真实升级/回滚结果。

## 发布说明

- 当前 Windows 资产未进行代码签名，安装或首次运行时可能出现未知发布者或 SmartScreen 提示。
- 当前版本不包含自动更新；后续版本需要手动下载和安装。
- v0.3.0 发布前必须通过 Windows x64 MSI/Portable 负载、安装/卸载、单进程、无监听端口、关闭退出、WebView2 媒体/主题和升级/回滚门禁。

# Image Tools v0.4.0

v0.4.0 在单进程 Rust/Tauri 架构内加入显式多协议图片 Provider，并把参考图扩展为可排序的多图工作流。

## 主要变化

- Provider 可显式选择 OpenAI Compatible、xAI Imagine 或 Gemini Native Image，不根据域名推断协议。
- Provider 设置新增独立的“检测联通性”和“获取可用模型”，成功发现的模型缓存在本地。
- xAI 支持文生图以及一至三张有序参考图；共享比例、分辨率和生成张数约束。
- Gemini 支持 prompt 后跟一至三张有序 `inlineData` 参考图；Flash/未知模型固定 1K，Pro 支持 1K/2K/4K，每次生成一张。
- Composer 可选择、追加、移除和左右调整最多三张参考图；生成历史保存参考图顺序和快照。
- 数据库升级到 schema v3，新增 Provider 协议、模型缓存和有序参考图记录；旧单参考图历史会自动回填为位置 0。
- 正式版仍只有一个 `Image Tools.exe` 进程，不启动 sidecar 或本地监听服务。

## Windows 资产

```text
Image-Tools-v0.4.0-Windows-x64.msi
Image-Tools-v0.4.0-Windows-x64-Portable.zip
```

Portable ZIP 内只有 `Image Tools.exe`。系统要求为 Windows x64 和可用的 Microsoft Edge WebView2 Runtime。

## 升级与回滚

从 v0.3.0 升级前必须备份整个工作区数据目录。v0.4.0 首次打开会把 `workbench.sqlite3` 从 schema v2 事务性迁移到 schema v3，并保留 Provider 密钥、默认 Provider、会话、结果和旧参考图历史。

v0.3.0 不认识 schema v3。需要回滚时，先卸载 v0.4.0、安装 v0.3.0，再恢复升级前保存的 schema-v2 工作区备份；不要让 v0.3.0 直接打开已经迁移的数据目录。

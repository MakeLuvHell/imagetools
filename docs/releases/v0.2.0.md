# Image Tools v0.2.0

Windows 桌面图片创作工作台的 Codex Desktop Windows 风格更新。

## 新增

- 重建 Windows 桌面视觉：克制侧栏、无框任务画布、统一任务流和底部双层 Composer。
- 新任务先保存为本地草稿，第一次有效提交时自动创建会话。
- 新增应用内 Provider 管理、会话重命名/删除和图片预览弹窗。
- 将比例、尺寸、质量、张数和高级选项收进 Composer 参数菜单。
- 支持运行中、成功、失败和本地网络失败的统一任务状态与安全重试。
- 新增本地 Lucide 图标、系统明暗主题和 Windows 最小窗口适配。

## 可靠性

- 乐观生成状态按会话和 submission ID 隔离。
- 生成请求发生普通运行时异常时，SQLite 记录会正确结束为失败状态。
- 快速双击提交只创建一个会话和一次生成。
- Provider 编辑时留空 API Key 会保留已保存密钥。

## 验证

- pytest：83 项
- Node：43 项
- Playwright：12 项
- 视觉基线：`1280x860`、`960x640`，浅色与深色主题
- Tauri/Cargo check

## Windows 安装包

GitHub Actions 将生成并附加：

- Windows x64 NSIS `.exe`
- Windows x64 MSI `.msi`

当前安装包没有代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。

# Image Tools v0.2.1

Windows 安装体验更新。

## 改进

- 使用新的 Image Tools 图稿作为应用、安装器、卸载器和应用内品牌图标。
- NSIS `.exe` 安装界面固定为简体中文。
- WiX/MSI `.msi` 安装界面使用 `zh-CN` 本地化。
- 提交完整的 Tauri 平台图标集，确保本地构建与 GitHub Actions 使用相同资源。

## Windows 安装包

GitHub Actions 将生成并附加：

- Windows x64 NSIS `.exe`
- Windows x64 MSI `.msi`

当前安装包没有代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。

## 验证

- Python 测试
- Node 测试
- Tauri/Cargo 配置检查
- 图标生成与前端资源一致性检查

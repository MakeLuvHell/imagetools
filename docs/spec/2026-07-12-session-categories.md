# 会话分类

## 目标

在图片创作工作台的侧栏中，为既有会话增加置顶、项目和普通会话三种清晰分类，让持续创作的任务可以稳定整理，同时不引入 Codex 专属的 Scheduled、Plugins 或 Sites 功能。

## 范围

- 会话可置顶或取消置顶；置顶会话独立显示在侧栏顶部。
- 用户可创建、重命名和删除项目；项目包含其下属会话。
- 用户可将会话分配到项目，或移回普通会话。
- 未置顶且没有项目的会话显示在“会话”分组。
- 删除项目不删除其中会话；会话自动回到普通会话。
- 现有数据库升级时保留全部 Provider、会话、轮次和图片数据。

## 不在范围

- 云同步、共享项目、项目封面、项目级参数或独立项目页面。
- Codex 专属导航和功能。

## 数据与 API

SQLite schema v2 新建 `projects` 表，并给 `sessions` 增加可空 `project_id` 与非空 `is_pinned`。项目删除通过外键将会话的 `project_id` 置空。会话 API 返回 `project_id` 和 `is_pinned`；项目提供完整 CRUD；会话提供置顶/取消置顶操作。

## 侧栏行为

侧栏按“置顶”、“项目”、“会话”垂直分区。没有对应内容的置顶和普通会话分区不显示；项目分区在有项目时显示，项目标题下列出会话。搜索在分组后的数据上过滤，不改变项目或会话的归属。项目和会话操作使用紧凑菜单与现有对话框语义，焦点和 Escape 行为沿用现有临时层工具。

## 验证

覆盖数据库迁移、项目 CRUD、分配与取消分配、置顶、删除项目后的会话保留；覆盖 API 公开字段和错误；覆盖前端分组渲染和 Playwright 侧栏交互。完成后运行 Python、Node、Playwright 和 Cargo 检查。

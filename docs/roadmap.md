# Image Tools 路线图

路线图用于说明方向，不是交付日期承诺。实际优先级会根据用户反馈、安全风险、Provider 协议变化和维护能力调整。

## 当前支持

- Windows x64 桌面端。
- MSI 安装包和单执行文件 Portable ZIP。
- OpenAI Compatible、xAI Imagine 和 Gemini Native Image。
- 本地 Provider、项目、会话、生成历史、参考图和结果存储。

## 近期方向

- 完善多 Provider 兼容性、错误诊断和模型能力展示。
- 改进数据导入导出、备份恢复和工作区管理体验。
- 持续完善键盘操作、辅助功能、窄窗口布局和减少动态效果。
- 建立常规 CI、安全报告、依赖更新、发布校验和与可复现发布记录。

## 评估中

- Windows 代码签名。
- 自动更新及其回滚和签名验证机制。
- Linux 和 macOS 正式支持及对应安装包。
- 系统凭据存储、导出脱敏和更细粒度的数据清理。

“评估中”不表示已经排期。Linux 和 macOS 可以用于部分开发验证，但当前公开发布和生命周期门禁只覆盖 Windows x64。

## 暂不计划

- 项目托管的云同步、账号或多用户服务。
- 将应用改造成对外提供本地 HTTP API 的后台服务。
- 内置完整图片编辑器或绕过 Provider 官方内容政策。

功能建议请使用 GitHub 的功能建议模板，说明目标用户、使用场景和为什么现有流程无法满足，而不只描述期望的界面控件。
